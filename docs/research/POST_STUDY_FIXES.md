# Post-study engineering fixes

This record separates changes made after inspecting the frozen experiments from
the evidence generated by those experiments. The old ledgers and reports remain
unchanged. These fixes must not be described as improving held-out or live-model
performance until a fresh protocol is executed on uninspected cases.

## September 9, 2026: bounded no-progress termination

### Observation that motivated the change

In the development-only Claude pilot, a missing-source case kept requesting
actions until the twelve-call allowance was exhausted. The resource budget
correctly prevented an unbounded loop, but expiry was the wrong semantic outcome:
the snapshot already declared a missing source, and further snapshot-bound calls
could not recover it.

### Control-layer change

The investigator loop now records exact query signatures and the set of newly
observed evidence IDs for each tool turn.

- When the snapshot declares missing sources and a query adds no new evidence,
  the loop terminates with `missing_source_no_progress`.
- When an identical query is replayed and adds no new evidence, the loop terminates
  with `repeated_query_no_progress`.
- Both paths mark the investigation incomplete. Existing coverage policy then
  routes the run to `HUMAN_REVIEW_REQUIRED`; the model cannot override this.
- The termination reason, query signature, missing-source list and new-evidence
  count are emitted into the observable trace and returned in the report.

The guard does not reject pagination because cursor-bearing requests have distinct
signatures, and it does not stop a repeated logical search when a new request
actually contributes evidence.

### Regression evidence

Two deterministic tests exercise the new behavior:

- a repeated no-progress query reaches review after two model calls rather than
  exhausting the default allowance;
- a declared missing-source/no-progress query reaches review after one model call.

The complete local suite passes 108 tests with one Elasticsearch test skipped when
the gated service is absent. The suite also runs without the prior Pydantic and
naive-UTC deprecation warnings after legacy contract cleanup in the same change.

### Claim boundary

This is regression evidence for deterministic harness behavior. No paid provider
rerun has been performed after the fix, so there is no claim of improved Claude
accuracy, latency, cost or completion rate. A future evaluation must use a fresh,
predeclared dataset and preserve the previous pilot as development history.
